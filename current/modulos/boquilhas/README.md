# Boquilhas

Página: `dist/31_BOQUILHAS_01_VISUAL_AUTHORITY_boquilhas.html`.

Pesquisa boquilha ou lote primeiro. Quando não há correspondência, oferece «Criar ferramenta» contextual, com tipo BQ e referência da pesquisa. O formulário regressa a Boquilhas e conserva os campos preenchidos. Criar um novo lote de uma boquilha existente continua a ser uma operação distinta da criação do `tool_id`.

## Navegação
O header e os separadores principais ocupam toda a largura. Os separadores de Registo, Boquilhas, Histórico e Definições ficam na linha seguinte. O painel das linhas de produção começa apenas abaixo destas duas linhas, preservando a navegação para Planeamento e Controlo.
